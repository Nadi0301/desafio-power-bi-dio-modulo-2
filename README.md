# desafio-power-bi-dio-modulo-2
# 📊 Desafio Power BI - Dashboard Financeiro (DIO)

Projeto de Business Intelligence desenvolvido como parte do desafio prático da plataforma **DIO (Digital Innovation One)**, utilizando a base de dados *Financials Sample*.

---

## 📌 Visão Geral do Relatório

O relatório foi estruturado em duas páginas para análise executiva e detalhada dos dados financeiros:

### 🔹 Página 1 - Panorama Geral e Indicadores
* **KPIs Principais:** Soma de Sales, Profit, Units Sold e Gross Sales.
* **Filtros Interativos:** Segmentador de dados por País (*Country*) em formato de blocos (*tiles*).
* **Alternância Dinâmica de Visuais:** Botões integrados com **Bookmarks (Indicadores)** e **Seleção** para alternar a visualização de gráficos entre **Vendas** e **Lucro** por Produto sem poluir a tela.

### 🔹 Página 2 - Detalhamento e Análise Geográfica
* **Matriz Financeira:** Detalhamento completo de Sales, Profit, Units Sold, COGS e Discounts agrupados por Segmento e País.
* **Mapa Geográfico:** Distribuição espacial de vendas por País com proporção de bolhas.
* **Navegação Interativa:** Navegador de Páginas ativado para alternar entre as visões com fluidez.

---

## 🛠️ Tecnologias e Recursos Utilizados
* **Power BI Desktop**
* **DAX / Métricas do Data Model**
* **Bookmarks e Selection Pane** (Gestão de estados dos visuais)
* **Page Navigator**
